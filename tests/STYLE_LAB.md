# Marsdove Style Lab

Open `demo/index.html` through any static server.

The page loads the complete framework stylesheet:

`/styles/marsdove.css`

It exercises:

- all button variants
- Icon
- typography primitives
- Input / Textarea
- custom Select
- NativeSelect / Option
- Checkbox / Radio
- Card / Badge / Divider
- Link / Spinner
- Avatar / Image
- List / ListItem
- Modal
- layout primitives

The browser console prints the smoke-test result table.
